Batch Image Resizer

A professional batch image resizing tool preserving aspect ratios.

Built with Python, CustomTkinter, and Pillow. Suitable for offline working.


WHAT IT DOES

Resize multiple images simultaneously to your desired dimensions. The default aspect ratios are preserved by the tool, so that the processed images never look stretched or distorted. For output, the formats JPEG, PNG, WebP, and BMP are supported.


COMPETITIVE ADVANTAGE

- Preserves aspect ratios; no stretched, squashed or distorted outcome
- Batch processing; resize all the content of a folder with one click
- Multiple output formats (JPEG, PNG, WebP, and BMP)
- Adjustable quality settings
- Works offline; your data won't leave your local storage
- Built by a precise physicist


HOW TO RUN

pip install customtkinter pillow
python batch_image_resizer.py
